Motivation and method

The learning problem is to find a short route through the six-region environment while the agent initially knows only the states, legal moves, and rewards it observes. For the original task, the robot starts in C and must reach F. A route such as C → B → F is better than a longer route because every non-target move costs one reward unit. The agent therefore needs to learn both which actions eventually reach the target and which of those actions preserve the most future reward.

Q-learning stores this information in a table indexed by a state and a legal action. The entry Q(s,a) is the current estimate of the total discounted reward obtained by taking action a in state s, then continuing with the best actions learned so far. After observing a transition to s' with reward r, the algorithm forms a target from the immediate reward and the best estimated future value:

target = r + γ maxa' Q(s',a')

The update moves the old estimate part of the way toward that target:

Q(s,a) ← Q(s,a) + α [target − Q(s,a)]

Here α is the learning rate and γ controls how much future reward matters. When the next state is the target, the episode ends, so there is no future action value to add. The implementation therefore uses target = r for a terminal transition. This prevents the terminal state from receiving an artificial bootstrap value.

The submitted implementation uses a tabular, deterministic environment. It initializes every legal Q-table entry to zero, runs one episode at a time, applies the update immediately after each move, and records the whole table after every episode. The episode stops on entry to the configured target or after 30 moves. The latter is a truncation without the target reward and prevents an exploratory loop from running forever.

Actions are selected with an ε-greedy policy. With probability ε, the agent samples uniformly from the legal adjacent regions to explore. Otherwise, it chooses an action with the largest current Q value; if several actions tie, one of the tied actions is sampled randomly. The main experiments use ε decreasing linearly from 0.4 to 0.1, learning rate α = 0.2, discount factor γ = 0.9, zero initialization, 10,000 episodes, and random seed 42. This combination lets the agent discover less obvious routes while gradually favoring the learned policy.

Experimental protocol

Unless a section says otherwise, the main runs initialize legal Q values to zero, use α = 0.2, γ = 0.9, 10,000 episodes, seed 42, and ε decreasing from 0.4 to 0.1 over 12,000 episodes. The final ε in this 10,000-episode run is about 0.15. Full per-episode Q tables and diagnostics are saved as CSV; the HTML figures are generated locally with the submitted Python standard-library scripts.

Interpretation and limitations

These ablations separate three sources of uncertainty: random initialization of the sampling trajectory, insufficient training budget, and the exploration schedule. The comparison is limited by the small deterministic graph, the manually interpreted adjacency, the fixed reward scale, and the use of one target and one start state in the ablations. Q* is available here only because this six-state deterministic environment is simple enough for an independent dynamic-programming check; in a larger unknown environment, such a reference may not be available. Observed stabilization and high return therefore remain empirical evidence rather than a guarantee of optimality.
